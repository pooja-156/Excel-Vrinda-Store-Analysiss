# Excel-Vrinda-Store-Analysis
# 🛍️ Vrinda Store Annual Report 2022

## 📌 Project Title
**Vrinda Store - Annual Sales & Order Analysis Dashboard (2022)**

## 📖 Short Description / Purpose
This project presents an interactive Excel-based dashboard to analyze the annual sales performance of Vrinda Store across various channels, product categories, and demographics for the year 2022. It offers a visual summary of key performance indicators to assist business decision-makers in identifying sales trends and customer behavior patterns.

## 🛠️ Tech Stack - List of Technologies Used
- **Microsoft Excel** (Pivot Tables, Charts, Slicers)
- **Excel Formulas** (SUMIFS, COUNTIFS, etc.)
- **Data Visualization** using:
  - Bar Charts
  - Pie Charts
  - Line Graphs
  - Slicers and Filters for interactivity

## 🗃️ Data Sources
- Internal order data from Vrinda Store
  - Sales amounts
  - Order IDs
  - Customer gender and age
  - Order channels (e.g., Flipkart, Amazon, Myntra)
  - Product categories (e.g., Blouse, Kurta, Ethnic Dress)
  - Geographic data (state-wise)

## ✨ Features / Highlights
- 📊 **Orders vs Sales Analysis**: Monthly breakdown of total sales and number of orders
- 🧑‍🤝‍🧑 **Sales: Men vs Women**: Gender-wise purchase share (Pie Chart)
- 📍 **Sales by State**: Top 10 states contributing to revenue
- 🔄 **Order Status Overview**: Visual representation of delivered, cancelled, refunded, and returned orders
- 📈 **Orders by Channel**: Distribution of orders across platforms like Amazon, Myntra, Flipkart, etc.
- 👥 **Orders: Age vs Gender**: Demographic insights based on customer age and gender
- 🧩 **Slicers for Filtering**:
  - By Month
  - By Channel
  - By Category
